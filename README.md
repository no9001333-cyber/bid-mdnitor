# 통신공사 입찰공고 자동 수집기

나라장터(G2B) · LH · 국방전자조달(D2B)에서 **통신공사** 관련 입찰공고를
**매일 자동으로 수집**하고, 웹페이지(대시보드)로 보여주는 프로그램입니다.

- 필터: 업종 = 통신 (키워드: 통신/정보통신/네트워크/광통신/무선통신)
- 지역: 용인 / 경기 / 전국
- 실행: 매일 오전 8시(KST) GitHub Actions가 자동 실행 → 결과를 GitHub Pages에 배포

코딩 경험이 없어도 아래 순서만 그대로 따라 하면 됩니다. 대략 30분 정도 걸립니다.

---

## 1단계. 공공데이터포털에서 API 키 3개 발급받기

모두 무료이고, 대부분 신청 즉시 자동 승인됩니다.

1. https://www.data.go.kr 회원가입 및 로그인
2. 아래 3개 서비스를 각각 검색해서 **활용신청**을 누르세요.
   - `조달청_나라장터 입찰공고정보서비스`
   - `한국토지주택공사 입찰공고정보`
   - `방위사업청_군수품조달정보 입찰공고`
3. [마이페이지 > 데이터활용 > Open API]에서 신청 목록을 보면
   각 서비스마다 **일반 인증키(Encoding)** 값이 있습니다. 이 3개 값을 복사해두세요.

> 참고: 승인까지 몇 시간 걸리는 경우도 있습니다. 키가 없는 서비스는 자동으로
> 건너뛰고 나머지만 수집하도록 만들어져 있으니, 급하면 나라장터 키만 먼저
> 넣고 시작해도 됩니다.

## 2단계. GitHub 저장소 만들기

1. https://github.com 가입 (이미 있으면 생략)
2. 오른쪽 위 **+ > New repository** 클릭
3. 저장소 이름을 `bid-monitor` 정도로 정하고 **Public**으로 생성
4. 이 폴더(`bid-monitor`) 안의 파일 전체를 새 저장소에 업로드하세요.
   - 컴퓨터에 Git이 없다면, 저장소 페이지의 **Add file > Upload files**로
     이 폴더의 모든 파일/폴더를 그대로 드래그해서 올리면 됩니다.

## 3단계. API 키를 GitHub에 등록하기 (Secrets)

1. 방금 만든 저장소 → **Settings > Secrets and variables > Actions**
2. **New repository secret** 클릭해서 아래 3개를 각각 등록
   - 이름: `G2B_SERVICE_KEY` → 값: 1단계에서 받은 나라장터 인증키
   - 이름: `LH_SERVICE_KEY` → 값: LH 인증키
   - 이름: `D2B_SERVICE_KEY` → 값: 국방전자조달 인증키

(코드에는 절대 키를 직접 적지 않습니다. GitHub이 안전하게 보관해서
자동 실행할 때만 몰래 넣어줍니다.)

## 4단계. GitHub Pages 켜기 (웹페이지로 보기)

1. 저장소 → **Settings > Pages**
2. **Source**를 `Deploy from a branch`로, **Branch**는 `main` / 폴더는 `/docs`로 설정 후 저장
3. 몇 분 후 `https://<내아이디>.github.io/bid-monitor/` 주소로 대시보드가 열립니다.

## 5단계. 첫 실행해보기

1. 저장소 → **Actions** 탭 → `매일 입찰공고 수집` 워크플로우 클릭
2. **Run workflow** 버튼을 눌러 수동으로 한 번 실행
3. 몇 분 뒤 완료되면 `data/bids.json`이 갱신되고, Pages 주소에서 결과 확인 가능

이후로는 **매일 오전 8시(KST)에 자동으로 실행**되어 공고를 새로 수집하고
대시보드를 갱신합니다. 아무것도 더 안 하셔도 됩니다.

## 폴더 구조

```
bid-monitor/
├── config.py              # 검색 키워드/지역 설정
├── main.py                # 전체 실행 (수집 → 저장 → 대시보드 생성)
├── generate_dashboard.py  # docs/index.html 생성
├── scrapers/
│   ├── g2b.py              # 나라장터
│   ├── lh.py                # LH
│   └── d2b.py               # 국방전자조달
├── data/bids.json         # 수집된 공고 데이터 (자동 갱신)
├── docs/index.html        # 대시보드 (GitHub Pages로 배포됨)
└── .github/workflows/daily.yml  # 매일 자동 실행 설정
```

## 검색 조건 바꾸고 싶을 때

`config.py` 파일의 `KEYWORDS`, `REGIONS` 값만 수정하면 됩니다.
예: 화성시도 보고 싶다면 `REGIONS = ["용인", "화성", "경기", "전국"]`

## 알아두세요

- 공공데이터포털 API는 가끔 필드명/오퍼레이션명이 개편됩니다. 특정 사이트에서
  수집이 0건으로 나오면, 해당 서비스의 data.go.kr 문서(Swagger)를 열어
  최신 파라미터명을 확인 후 `scrapers/` 안의 해당 파일만 손보면 됩니다.
- 이 대시보드는 참고용입니다. 투찰 전에는 반드시 원본 사이트(나라장터/LH/D2B)에서
  최신 공고 내용을 다시 확인하세요.
